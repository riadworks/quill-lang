Quill
lang. reference 0.1
a general-purpose language

Write it once,
read it back like prose.

Quill has classes, exceptions, a module system, and its own web server. The syntax reads at a glance instead of needing to be decoded.

> quill
opens a REPL — no build step, no config
task.ql 
class Task:
    pull init(title):
        self.title = title
        self.done = false

    pull complete():
        self.done = true
        return f"{self.title} - done"

# first-class functions, real closures
let tasks = [Task("Write docs"), Task("Ship it")]
for t in tasks:
    print(t.complete())

What's actually in it

A grammar with a full language behind it.

OOP

Classes, properly

Fields, methods, single inheritance. super.method() resolves correctly through arbitrarily deep chains.

ERRORS

Exceptions that mean it

try / except / finally catches your own raises and built-in runtime errors the same way, every time.

SCALE

A module system

import "file.ql" as name. A program can grow past one file and stay organized.

STDLIB

Methods that chain

.trim().upper().split() on strings, lists, and maps alike, plus file I/O and 20-odd built-ins.

NETWORK

Ships its own web server

serve(port, handler) turns a Quill function into real HTTP responses without installing a framework first.

DX

Errors with a line number

Bad syntax, a missing file, a divide by zero: whatever fails, it names the line and says plainly what went wrong.

Built and tested as real programs

CLI app

A persistent task manager

Add, complete, and remove tasks from a terminal menu. Saves to disk, reloads on the next run, and catches a bad menu choice without crashing.

Website

The same app, in a browser

Same task class, same storage format, a form and two buttons instead of a menu — served entirely by Quill's own serve(), no framework underneath.
