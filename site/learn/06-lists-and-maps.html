Lesson 6

Lists & Maps

Quill's two collection types. Both are mutable, both can hold a mix of any value type, and both come with a decent set of built-in methods.

Lists

let nums = [5, 3, 8, 1]
print(nums[0])     # 5
print(nums[-1])    # 1  - negative indexes count from the end
nums[0] = 99      # indexing assigns too

Indexing out of range (in either direction) is a clear runtime error, never silent nil or a wraparound. There's also no slice syntax like Python's xs[1:3] — reach for the slice(list, start, end) builtin instead: slice(nums, 1, 3).

List methods

MethodDoes
.push(x)Appends x in place.
.pop() / .pop(i)Removes and returns the last item, or the item at index i.
.reverse()Returns a new reversed list (doesn't mutate).
.sort()Returns a new sorted list (doesn't mutate); needs all-comparable elements.
.contains(x)Whether x is in the list (deep equality).
.index_of(x)First index of x, or -1.
.join(sep)Joins elements into a string, converting each with str() first.
.map(fn)New list of fn(item) for each item.
.filter(fn)New list of items where fn(item) is truthy.
.reduce(fn, init)Folds the list into one value: acc = fn(acc, item) for each item, starting from init.
nums.push(9)
print(nums.sort())                                   # [1, 3, 5, 8, 9, 99]
print(nums.filter(pull(x): return x > 4))       # [5, 8, 9, 99]
print(nums.reduce(pull(acc, x): return acc + x, 0))   # sum of all elements
print(["a", "b", "c"].join("-"))                # "a-b-c"

.sort() and .reverse() returning new lists (rather than mutating and returning nil, like Python's list.sort() does) is worth remembering if you're coming from Python — write nums = nums.sort() if you want the variable itself updated.

Every list method above also exists as a standalone function taking the list as its first argument — push(nums, 9) works exactly like nums.push(9). Both forms do the same thing; the method form is just nicer for chaining.

Maps

let person = {"name": "Ada", "age": 36}
print(person["name"])   # "Ada"  - bracket indexing
print(person.name)      # "Ada"  - dot access works too, for keys that look like names
person["age"] = 37     # assignment through either form

Looking up a key that doesn't exist with [ ] is a runtime error ("key not found"); assigning through [ ] to a new key adds it. Map keys are restricted to strings, numbers, and booleans — a list, map, or class instance can't be a key.

Map methods

MethodDoes
.keys()List of the map's keys.
.values()List of the map's values.
.items()List of [key, value] pairs.
.has(k)Whether k is a key in the map.
.get(k, default)The value at k, or default (or nil) if it's missing.

As with lists, top-level equivalents exist: keys(m), values(m), items(m). There's also a general-purpose top-level has(container, needle) that works on a map (key), a list (element), or a string (substring) — one function, three containers.

Gotcha

Dot access checks the map's actual data first: m.get returns the method only when there's no key literally named "get" in m. If a map happens to have a data key with the same name as a method ("keys", "has", "get"...), dot access returns that stored value instead — use m["get"] if you ever need to be unambiguous, or just avoid using method names as map keys.

Destructuring assignment

A list can be unpacked into several names at once, whether declaring new ones with let or reassigning existing ones without it: 

let a, b = [1, 2]     # declares two new names
a, b = [b, a]         # reassigns them - this is the idiomatic swap
print(f"a={a} b={b}")    # a=2 b=1

The number of names must match the list's length exactly, or it's a runtime error ("too many/few values to unpack") — never silent truncation or nil-padding. The same unpacking is what powers for key, value in m.items(): from the previous lesson: each [key, value] pair gets unpacked fresh on every iteration.

Comprehensions

List and map comprehensions both work the same way Python's do, including chaining multiple for/if clauses:

let squares = [x * x for x in range(5) if x > 0]
print(squares)   # [1, 4, 9, 16]

let pairs = [x + y for x in [1, 2] for y in [10, 20] if x != y]
print(pairs)     # [11, 21, 12, 22]

let upper = {k: v.upper() for k, v in person.items() if type(v) == "string"}

Check yourself

  1. After let xs = [3, 1, 2], what does xs.sort() return, and what is xs afterward?

    xs.sort() returns the new list [1, 2, 3], but xs itself is still [3, 1, 2] — .sort() doesn't mutate. You'd need xs = xs.sort() to update it.

  2. What does let a, b, c = [1, 2] do?

    Raises a runtime error: "too few values to unpack (expected 3, got 2)".
