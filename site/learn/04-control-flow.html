Lesson 4

Control Flow

if, while, and for-in cover everything — there's no switch/match statement and no C-style three-part for (;;) loop.

if / elif / else

if score > 90:
    print("A")
elif score > 80:
    print("B")
elif score > 70:
    print("C")
else:
    print("F")

elif is its own keyword, not else if — and as many elif branches as you like are allowed. Every branch's body can also be the single-line form from Lesson 1 (if x: print("yes")) when it's one statement.

while

let i = 0
while i < 5:
    print(i)
    i += 1

There's no do/while variant — only the check-first form.

for ... in

for iterates a list, a string (character by character), or a map (its keys):

for n in [1, 2, 3]:
    print(n)

for ch in "hi":
    print(ch)          # "h" then "i"

let person = {"name": "Ada", "age": 36}
for key in person:
    print(f"{key} = {person[key]}")

To loop a fixed number of times, reach for range(), which returns a real list: range(n) gives 0 up to (not including) n; range(start, end) and range(start, end, step) work like you'd expect. 

for n in range(1, 21):
    if n % 15 == 0:
        print("FizzBuzz")
    elif n % 3 == 0:
        print("Fizz")
    elif n % 5 == 0:
        print("Buzz")
    else:
        print(n)

for also unpacks a pair of loop variables from each item, which is the natural way to walk a map's entries — .items() returns a list of [key, value] pairs: 

for key, value in person.items():
    print(f"{key} => {value}")

Lesson 6 covers the destructuring rules behind that in full.

break and continue

Both work exactly as in Python or C, inside either loop form:

for n in range(10):
    if n == 3:
        continue       # skip 3, keep going
    if n == 6:
        break          # stop the loop entirely
    print(n)

Check yourself

  1. What does range(1, 10, 2) produce?

    [1, 3, 5, 7, 9] — start at 1, stop before 10, step by 2.

  2. What does for ch in "cat": iterate over?

    Each character as its own one-character string, in order: "c", "a", "t".
