Course overview

Learn Quill from scratch.

Fifteen lessons, in order, covering the whole language: every keyword, every built-in function, every method on every type. No prior Quill experience assumed, though knowing roughly how any C-family or Python-family language works will make the first few lessons go fast. Every example on every page has actually been run through the real interpreter — nothing here is guessed at.

Before you start

Install Quill from source (there's no PyPI package yet): 

git clone https://github.com/riadworks/quill-lang.git
cd quill-lang
python -m venv .venv
.venv\Scripts\pip install -e .

That gives you a quill command. Lesson 1 covers the rest.

What's covered

Read top to bottom for a first pass, or jump straight to whatever you need from the sidebar.

1. Getting Started

Installing Quill, the difference between the REPL and running a script, your first program, and how comments work.

2. Variables & Types

let, Quill's five value types, dynamic typing, truthiness, and the type()/str()/num()/bool() conversion functions.

3. Operators & Expressions

Arithmetic, comparison, and logical operators, precedence and associativity, the ternary expression, and a couple of real gotchas around chained comparisons.

4. Control Flow

if/elif/else, while, for-in over lists, strings, maps, and ranges, plus break and continue.

5. Functions & Closures

pull, parameters and returns (including defaults — evaluated fresh per call, so no Python-style shared-mutable-default surprise), functions as values, anonymous functions, and closures that capture and mutate an enclosing variable.

6. Lists & Maps

Literals, indexing, every built-in method, destructuring assignment, and list/map comprehensions.

7. Strings & Interpolation

Plain strings vs. f-strings, escape sequences, every string method, and exactly how {expr} interpolation is parsed (which explains some of its sharper edges).

8. Classes & Inheritance

Defining classes, init and self, single inheritance, and super.

9. Operator Overloading

Making your own types work with +, ==, <, unary -, and print(), the Python-dunder way.

10. Exceptions

try/except/finally, raise-ing arbitrary values, and how built-in runtime errors surface to an except block.

11. Modules

Splitting a program across files with import "file.ql" as name, and how module namespaces actually work under the hood.

12. Standard Library

Every built-in function, grouped by what it's for: math and statistics, collections, files, JSON/CSV, hashing and encoding, regular expressions, bitwise operations, type predicates, program control (assert/exit), and more.

13. Networking

Serving real HTTP requests with serve(), and making outbound requests with http_get/http_post — building a tiny web app end to end.

14. Building Real Programs

A guided tour of the six full applications shipped with the project, and the real bugs that building them found in the language itself.

15. What's Next

What Quill deliberately leaves out, why, and where to go from here.
