Lesson 1

Getting Started

Quill is a small, dynamically typed scripting language with a Python-like feel: indentation instead of braces, but its own keywords and a few of its own ideas. This lesson gets it installed and gets one program running.

Installing Quill

There's no PyPI package yet, so Quill installs straight from source. You'll need Python 3.10 or newer. 

git clone https://github.com/riadworks/quill-lang.git
cd quill-lang
python -m venv .venv
.venv\Scripts\pip install -e .

That last command installs Quill in "editable" mode and adds a quill command to your virtual environment. If you'd rather have quill on your PATH from any terminal, use pipx install . from the project folder instead.

REPL vs. running a file

Typing quill with no arguments starts an interactive REPL (read-eval-print loop) — type a line, see it run immediately: 

> quill
Quill REPL. Ctrl+D (or Ctrl+Z then Enter on Windows) to exit.
>>> print("hi")
hi
>>> let x = 2 + 2
>>> print(x)
4

The REPL is smart enough to know when a line isn't finished yet — if it ends in :, or you've opened a bracket you haven't closed, it shows a ... continuation prompt and keeps reading until the block is complete.

To run a whole program from a file instead, save it with a .ql extension and pass the path. Anything typed after the path is available inside the script through args() — quill script.ql foo bar makes args() return ["foo", "bar"]: 

quill script.ql
quill script.ql foo bar

Your first program

Save this as hello.ql:

print("Hello, World!")

let name = "Ada"
print(f"Hello, {name}!")

Then run it:

quill hello.ql
Hello, World!
Hello, Ada!

Two things worth clocking already: print(...) is a function call with parentheses, and a plain "..." string never interpolates — only a string prefixed with f does. Lesson 7 covers strings in full.

Comments

Quill only has line comments, starting with # and running to the end of the line. There's no block-comment syntax. 

# this whole line is a comment
let x = 5   # so is this part of the line

Indentation is the block syntax

Like Python, Quill has no { } braces around blocks — the indentation itself marks where a block starts and ends. A block always follows a line ending in :. Mixing tabs and spaces inconsistently within a block is a lex error, so pick one (spaces are the convention used throughout this course and the project's own source) and stick with it. 

if true:
    print("this line is inside the if")
print("this line is not")

For a body that's a single statement, you can also skip the indented block entirely and write it right after the colon on the same line — you'll see this throughout the course wherever it keeps an example short: 

if x > 0: print("positive")
else: print("non-positive")

Check yourself

  1. What's the difference between running quill and quill script.ql?

    quill with no file starts an interactive REPL that runs each line (or block) as you type it. quill script.ql runs an entire file non-interactively from top to bottom and exits.

  2. Will this print anything? Why or why not? 
    print("Value: {x}")

    Yes, it prints the literal text Value: {x} — {x} is not interpolated because the string has no f prefix. To interpolate, it would need to be written f"Value: {x}".
